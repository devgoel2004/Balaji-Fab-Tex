# Balaji Fab Tex — React Homepage

React + Vite frontend for a premium B2B textile manufacturer website.

## Run locally
1. Install Node.js if needed.
2. In this project folder run `npm install`.
3. Run `npm run dev`.
4. Open the local URL shown by Vite (usually http://localhost:5173).

## Build
Run `npm run build` to create the production build in `dist/`.

## Brand assets
The `src/assets/` directory includes the previously created Balaji Fab Tex logos. `public/favicon.png` is a cropped sofa-mark favicon. Replace product photography in `src/main.jsx` with actual product catalogue images when ready.
